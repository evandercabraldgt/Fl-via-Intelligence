# Flávia Bezerra Studio — PWA Cloudflare

Esta versão mantém o Studio e acrescenta instalação como aplicativo web.

## Publicação
Extraia o ZIP e envie/substitua o conteúdo na branch `main` do repositório conectado à Cloudflare Pages, mantendo a estrutura `public/` e `functions/`. Preserve a variável `GROQ_API_KEY` em Production.

## Instalação
Android/Chrome: abra o site e use Instalar aplicativo ou o menu do navegador. iPhone/iPad: abra no Safari, toque em Compartilhar e escolha Adicionar à Tela de Início.

PWA não significa publicação na App Store ou Google Play. A inteligência depende de internet. O service worker não armazena chamadas ou respostas da API.
